# Country code adapter data

`country-alpha2.json` maps ISO alpha-2 country identifiers to the numeric country identifiers used by this app's existing atlas. Derived from Luke Duncalfe's [ISO-3166-Countries-with-Regional-Codes v10.0](https://github.com/lukes/ISO-3166-Countries-with-Regional-Codes/tree/v10.0), `slim-2/slim-2.json`; filtered to this app's country catalog and supplemented with `XK → XKX` for Kosovo.
