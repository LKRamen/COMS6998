# Travel map data

Generated from world-atlas 2.0.2 (Natural Earth 4.1.0, 1:50m boundaries).
Natural Earth geometry is public domain. The redistribution's ISC license is
preserved in WORLD-ATLAS-LICENSE.txt. Regenerate with `node scripts/build-world-map.mjs`.

The catalog includes 235 countries and territories, including small island states.
Antarctica is excluded from visit tracking. Geometries sharing an ISO numeric code
are grouped (for example Australia). Kosovo uses the internal code XKX. Other
uncoded disputed regions are drawn as context but are not separate catalog entries.
Boundaries are illustrative, not a statement on sovereignty.

SVG paths are generated once and committed; no map API keys, live map tiles, or
external geography requests are needed to render the application.
